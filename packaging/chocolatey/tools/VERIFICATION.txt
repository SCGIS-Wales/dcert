VERIFICATION

Verification is intended to assist the Chocolatey moderators and users in
verifying that the binaries this package installs are authentic.

This package does not embed any binaries. At install time it downloads the
official release archive from the dcert GitHub Releases page:

    https://github.com/SCGIS-Wales/dcert/releases/download/v<version>/dcert-x86_64-pc-windows-msvc.zip

The SHA256 checksum embedded in tools\chocolateyInstall.ps1 (checksum64) is
computed from that exact release artifact during the dcert CI release pipeline,
and Chocolatey verifies it before extracting the binaries.

To verify manually:

  1. Download the archive from the release URL above for the package version.
  2. Compute its SHA256:
         Get-FileHash .\dcert-x86_64-pc-windows-msvc.zip -Algorithm SHA256
  3. Confirm it matches the checksum64 value in chocolateyInstall.ps1.

The binaries (dcert.exe, dcert-mcp.exe) are built from source on GitHub-hosted
runners; the build is defined in .github/workflows/ci.yml in the repository.
